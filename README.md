# Personal Tooling Inventory

A practical inventory of the AI-agent tools, MCP integrations, CLI utilities, macOS workflows, applications, and related GitHub projects found in one personal workstation setup.

The inventory is ordered by usefulness to autonomous agents first, user-facing workflows second, and general applications and utilities after that. Likely bundled Skills and application Quick Actions are separated into a final section.

## Files

- [INVENTORY.md](INVENTORY.md) — the actual inventory and audit notes.

## How it is compiled

This is a manual snapshot assembled by inspecting local MCP configurations, installed CLI tools, Skills directories, macOS Quick Actions, applications, and related GitHub repositories. Each entry is labeled or described according to the evidence available: locally installed, configured, source repository only, or inferred to be bundled with an application.

A repository existing on GitHub is not treated as proof that its software is installed or running. Configuration files are not treated as proof that a service is reachable. Ambiguous application-provided assets are placed in the final section.

## Scope

Last audited: **2026-11-04**. The audit covers the primary Intel MacBook Pro and the GitHub accounts and repositories inspected at that time. It is not a live status monitor, a security assessment, or a guarantee that every integration still works.

The inventory intentionally excludes credentials, tokens, private endpoints, and other secrets. It should be refreshed after major changes to the workstation or toolchain.
